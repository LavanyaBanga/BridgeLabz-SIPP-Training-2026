## How to Run the Programs

### 1. Clone the repository

```bash
git clone https://github.com/LavanyaBanga/BridgeLabz-SIPP-Training-2026.git
```

### 2. Navigate to the project directory

```bash
cd BridgeLabz-SIPP-Training-2026
```

### 3. Open the project

Open the repository in **IntelliJ IDEA**, VS Code, Eclipse, or any Java-supported IDE.

### 4. Compile a Java program

```bash
javac FileName.java
```

### 5. Run the program

```bash
java FileName
```
